# ZCam

ZCam is a CAM (Computer Aided Manufacturing) program. It allows you to import and edit CAD data (DXF, SVG). ZCam generates control data for Galvo fiber lasers or G-code for CNC machines.

version with a 60W MOPA Fiber Laser.
